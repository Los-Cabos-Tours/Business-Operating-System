BOS Tools

Backup & Restore — works with the main CRM on this same site.

Download Full Backup

Exports every record of the system (guests, bookings, tasks, operators, settings, history) into one JSON file you can keep safely offline.

Restore From Backup

Import a backup file made by this tool. It is checked for validity first, and a safety snapshot of your current data is taken before anything is overwritten.

Restoring replaces current records with the backup contents. Download a fresh backup first if unsure.
